AEROV GCS 1.0.0, the first test release for Windows.

Download AEROV-GCS-Setup-1.0.0.exe below and run it. Windows will show "Windows protected your PC" because the app is not code signed yet: click More info, then Run anyway. After installing, the app updates itself when a new version comes out (never while the vehicle is armed).

AEROV-GCS-1.0.0.exe is a portable copy that runs without installing, but it does not update itself.

Works with ArduPilot (Copter, Plane, Rover, Sub) over USB, telemetry radio, WiFi, TCP and UDP, and with Betaflight over USB or WiFi (TCP, for example an ESP bridge at 192.168.4.1:5760).

Known limits in this version:
- RTSP and UDP video cannot play directly. Relay them with MediaMTX and use WebRTC (WHEP).
- No mission download from the vehicle, and no geofence or rally points yet.

Found a problem? Send what you did, a screenshot and the time it happened.

This is a test build. Free to use for testing; please do not redistribute it.
